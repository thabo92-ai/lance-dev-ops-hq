# Orbit by LanceDevOps

A free launch experience for Orbit, the multi-provider AI conversation app.

**This Static Space is the public launch page.** The working application, sign-in, encrypted per-user API connections and conversation storage run at https://orbit-console.thabo595.chatgpt.site. Use **Open Orbit** to enter the actual app in a new tab, where sign-in can work reliably.

Connect your own provider API keys, including OpenAI, Anthropic, xAI, Google and DeepSeek, or configure another compatible connection. Install Orbit on a compatible device from inside the app. Each AI can have its own model and voice. Team members respond in turn; Nova compiles the available contributions. Orbit itself is free to use. Provider API calls are billed by the providers, separately from their consumer chat subscriptions. The current beta has a 60-stage daily allowance per account.

No provider keys, access tokens, private chats or server configuration are included in this Space. Do not add API keys to a Static Space: its browser-delivered code is public.
