# Orbit by LanceDevOps · 0.3 beta

**Your AI, in sync.** Independent minds. One conversation.

[Open Orbit](https://orbit-console.thabo595.chatgpt.site) · [Quick guide](https://orbit-console.thabo595.chatgpt.site/guide) · [LanceDevOps](https://lancedevops.com)

A free installable web app with a galaxy interface, your choice of AI providers and models, distinct voices, shared conversations and Nova synthesis.

## Get started

1. Open Orbit and sign in with ChatGPT.
2. Connect your own provider API key in Connections and select a model.
3. Start a conversation, choose Team chat or One AI, and enable voices if you want them.
4. Use Install Orbit to add it to a compatible device.

Orbit itself is free. Provider API calls and natural speech are billed separately. A consumer chat subscription may not include API credit. Internet is required. The app does not run generated code or control your computer.

This kit launches the hosted application. It is not an independent backend, native app binary or full backend source release. It contains no credentials or conversations.
